CoReader 0.1.5 · Windows x64

界面采用小米 MiSans 字体。

安装版可从 Windows「已安装的应用」、开始菜单或安装目录里的 unins000.exe 卸载。卸载保留文献、批注和设置。便携版请完整解压 ZIP，再双击 CoReader.exe。升级前请关闭旧版窗口。首页侧栏底部与设置页均显示当前版本。每次启动后会在后台检查 GitHub，发现新版时可点击提示查看发布。

使用方式
在论文库点击「从文件夹导入」，可一次收录文件夹及其子文件夹里的 PDF。每篇论文均可查看阅读进度，读到最后一页时自动显示「已读」。在分类内勾选论文后可批量移出。在详情里可选择已有标签，也可创建新标签。
设置：从首页侧栏底部或阅读界面左下角的「设置」进入。模型与账号页用卡片两侧的箭头切换服务商，点击卡片打开连接设置。连接后，在任务模型中设置问答和翻译，点击「保存设置」。显示设置页可切换主题和功能栏布局。阅读设置页可开启划词自动翻译或自动打开翻译浮窗。
打开 PDF 后可从侧边按钮打开目录，或从顶部胶囊切换原文和对照。两侧均可连续滚动并同步当前阅读位置，悬停段落时两侧显示高亮。插图、表格与独立公式从原 PDF 裁切后按阅读顺序插入。拖中间分隔线可调整宽度。对照右上角可选择翻译本页、本章或全文。翻译按段保存在本机，暂停后可继续剩余段落。
打开 PDF 后，可在「阅读助手」卡片提问或总结本页。选中文本后点「引用至阅读助手」可逐次加入多段原文。回答中的引用可跳回页码。阅读助手使用设置页中选定的问答模型，对话按文献保存。
划选英文点击「翻译」，默认使用随包附带的 Haidass-Translate-143M。可在「模型设置 → 任务模型 → 翻译」选择 Hy-MT2-1.8B（离线），保存后划词和对照翻译都会使用它。两个离线模型都支持断网使用。
在功能栏顶栏可切换停靠位置、一键缩小或展开栏内全部卡片，并保存、切换或删除最多三个自定义布局。点击缩小的卡片可单独展开。收起整栏后，点击贴边的「功能栏」重新打开。底部停靠时，从术语和高亮批注卡片左侧选择条目，右侧会显示详情。把卡片顶栏拖到阅读区，松手后卡片会自动展开。拖回功能栏后恢复拖出前的展开或缩小状态。功能栏停靠底部时，拖动中的卡片在阅读区显示为横向胶囊，进入功能栏后切换为竖向。按住 Shift 可继续划选并连翻。
1. 打开 PDF，从顶部“设置”配置服务商、模型和推理强度。
2. 点击「论文分析」内容区右上角的开始图标。生成结果后可重新分析或复制，点击感叹号可查看模型、推理强度、时间和分析范围。可展开报告，汇总失败时可重试汇总。
3. 点击「参考文献」内容区右上角的开始图标，有结果后可重新整理。可在模型设置中添加可选的 OpenAlex API Key。
4. 在 PDF 原文中悬停或右键图片、表格和公式，即可解释对应内容。也可点击顶部「截图内容解析」并框选需要解释的区域。解析结果按论文保存在“内容解析”卡片中，可按位置或时间排序。

模型连接
· ChatGPT 订阅：点击「连接 ChatGPT」，在系统浏览器完成授权。可在卡片中切换账号、刷新模型和打开官方用量页面。授权和模型请求跟随 Windows 系统代理设置。
· DeepSeek：输入平台 API Key，点击「验证并连接」。卡片可查询 API 可用余额。
· GLM：使用智谱开放平台 API Key。可填具体模型 ID，或在目录不可用时用默认模型进行一次简短验证。
· Claude：点击账号卡片，从连接设置打开 Claude Console 创建 API Key，再回到阅读器验证。发起请求后，卡片可查看服务返回的限流余量；累计用量可在 Claude Console 查看。
· Kimi：在同一张卡片里切换「Kimi API」和「Kimi Code」。Kimi API 可配置开放平台 API Key、查询余额。Kimi Code 需安装新版 Kimi Code CLI，再点击「登录 Kimi Code」在浏览器授权。
· 火山方舟：填写方舟 API Key 读取模型目录，或指定已开通的 Model ID 或推理接入点 ID。
· WorkBuddy：先登录 CodeBuddy CLI，再点击「检测 CodeBuddy CLI 账号」。
· 自定义 API：填写 OpenAI 兼容的 API 地址、可选 API Key，以及可选的模型 ID。模型 ID 留空时从服务读取模型目录。
· 任务列表只显示已连接账号返回的模型，翻译也可使用离线模型。

电子文献与已保存的研究记录可离线查看。发起模型任务时，相关原文或裁剪图像会发送到所选服务。云端登录和实际用量需使用自己的账号。
